مراحل گرفتن فایل APK در اندروید استودیو (Android Studio):

۱. نرم‌افزار Android Studio را باز کنید.
۲. روی گزینه Open یا Open an Existing Project کلیک کنید.
۳. پوشه زیر را انتخاب کنید:
   c:\Users\Administrator\Downloads\Game\android_project

۴. منتظر بمانید تا Gradle پروژه را بارگذاری کند (Sync شود).
۵. از منوی بالای نرم‌افزار روی گزینه زیر کلیک کنید:
   Build -> Build Bundle(s) / APK(s) -> Build APK(s)

۶. در کمتر از ۱۰ ثانیه پیام "APK(s) generated successfully" ظاهر می‌شود و فایل APK آماده نصب است!
